Direct-to-S3 Multi-File Streaming in Laravel Vapor

Date: 2026-04-10 | Laravel AWS Vapor S3 Pre-signed Livewire

01. The Problem

AWS Lambda imposes a strict 6MB payload limit (effectively ~4.5MB for base64 encoded streams) on synchronous invocations. Uploading high-res documents or batch photo files through standard Laravel HTTP controllers fails or consumes excessive Lambda RAM and execution budget.

02. Solution Pattern: Direct S3 Client Uploads

Bypass Lambda execution entirely by generating short-lived S3 pre-signed upload URLs on the backend, having the browser stream files directly to Amazon S3, and subsequently notifying the Laravel backend with the confirmed S3 key:

// 1. Generate Pre-signed S3 URL (Laravel Action)
public function generateUploadUrl(Request $request): JsonResponse
{
    $uuid = (string) Str::uuid();
    $extension = $request->input('extension');
    $key = "uploads/{$uuid}.{$extension}";

    $url = Storage::disk('s3')->temporaryUploadUrl(
        $key,
        now()->addMinutes(10),
        ['ContentType' => $request->input('content_type')]
    );

    return response()->json([
        'url' => $url['url'],
        'headers' => $url['headers'],
        'key' => $key
    ]);
}
// 2. Frontend Direct S3 Stream (Alpine / Fetch)
async function uploadFileToS3(file) {
    // Step 1: Request pre-signed URL from API
    const meta = await fetch('/api/uploads/signed-url', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ extension: file.name.split('.').pop(), content_type: file.type })
    }).then(r => r.json());

    // Step 2: Stream binary direct to S3
    await fetch(meta.url, {
        method: 'PUT',
        headers: meta.headers,
        body: file
    });

    return meta.key; // Safe S3 reference with 0 Lambda payload overhead
}

03. Benefits

  • Bypasses Payload Limits: Supports large multi-file uploads (100MB+) with zero Lambda payload exceptions.
  • Zero Compute Memory Cost: Lambda instances don't spend execution cycles buffering files into PHP memory.
